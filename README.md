# 📱 Kronoly App

Aplicação mobile desenvolvida em **React Native** para gerenciamento de serviços, agendamentos e produtividade, com foco em organização, eficiência operacional e experiência do usuário.

---

## 🚀 Sobre o projeto

O **Kronoly App** é uma solução voltada para facilitar o controle de atividades, serviços e agendas, permitindo que usuários organizem suas demandas de forma simples, prática e intuitiva.

A aplicação foi projetada com foco em:

- 📅 Gestão de tempo e serviços  
- 📊 Organização de atividades  
- ⚙️ Produtividade no dia a dia  
- 📱 Experiência mobile moderna  

---

## 🧠 Objetivo

O objetivo do projeto é fornecer uma ferramenta eficiente para:

- Gerenciar serviços e tarefas  
- Controlar tempo e produtividade  
- Centralizar informações importantes  
- Apoiar a tomada de decisão  

---

## 🔌 Como executar o projeto

### Pré-requisitos

- Node.js instalado  
- React Native CLI ou Expo  
- Android Studio ou dispositivo físico  

---

### Passos

```bash
# Clone o repositório
git clone https://github.com/Jonnathan2020/kronolyApp.git

# Acesse a pasta
cd kronolyApp

# Instale as dependências
npm install

# Execute o projeto
npx react-native run-android
```

> Caso utilize Expo:
```bash
npx expo start
```
